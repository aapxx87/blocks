Blocks - сборка для GitHub Pages

Загрузите СОДЕРЖИМОЕ этой папки в корень репозитория: index.html, assets/, .nojekyll и THREE-LICENSE.txt.
В GitHub откройте Settings > Pages > Deploy from a branch, выберите main и / (root), нажмите Save.
Сайт работает и на username.github.io, и на username.github.io/имя-репозитория/. Сборка на GitHub и серверная часть не нужны.
Папку assets нужно сохранить целиком. ZIP перед загрузкой нужно распаковать.

Что загружается:
- HTML, CSS и небольшой скрипт интерфейса: около 60 КБ без сжатия.
- 3D-движок отдельным модулем после первого отображения страницы.
- Галерея подготавливается при приближении к ней; готовые модели сохраняются в памяти для быстрого переключения.
- Превью видео загружается рядом с роликом. Full HD MP4 (19.0 МБ) - только после Play.
- Имена ресурсов содержат хеш содержимого: обновления не конфликтуют с кешем браузера.
- Все необходимые файлы локальные, внешних CDN, API и шрифтов нет.

В дизайне, сценах и профилях атмосфер сохранена текущая версия прототипа.
Для локальной проверки нужен обычный HTTP-сервер. Двойной клик по index.html не заменяет GitHub Pages.
Контакты открывают почтовую программу или Telegram; формы и базы заявок нет.
